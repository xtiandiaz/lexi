# Lexi

A very simple gamified app that reads terms (mostly words) from listings available at [Lexicon](https://github.com/xtiandiaz/lexicon). Then shows them one by one as flashcards, shuffling their letters, and asking us to type in the term correctly. For every completed term, the card will enable links to their corresponding dictionaries, (image) Web search, Wikipedia and translators, to learn more about the terms.

Feel free to try it out: https://xtiandiaz.github.io/lexi

The app is available in 3 languages, English (en), Spanish (es), and Finnish (fi), supporting basic localization.

Lexi was the first app I developed while learning Vue3. It was co-developed with [Vueties](https://github.com/xtiandiaz/vueties), a collection of components for Vue3 apps which are shared by multiple other exercise apps, and the [design tokens](https://github.com/xtiandiaz/design-tokens) of my preference.

## V2

I've been thinking of extending and enhancing this app by offering the possibility to create listings, using a simple syntax that will be parsed and turned into flashcards. The cards then could be explored, for which the app would offers various tools and game modes to learn the desired concepts, either terms or phrases, probably also employing the _spaced repetition_ technique.

However, because this kind of tools are available (usually for free) from multiple sources, I don't see yet the point to invest more time on it. Feel free to share your opinions.
